Kaeno

One continuing personal-assistant conversation. Trusted read-only specialists work in the background; saved results return as cards and one follow-up attempt.

Try it

npm install
npm start

On first run, type an OpenAI API key into the terminal prompt. It is visible so you can check it; Ctrl+R hides or reveals it. Visible input can be recorded by your terminal. The key is saved locally in a private, unencrypted file. No demo mode or environment-variable setup.

One owner

custom pi-tui chat → one Durable Harness → one SQLite store
                          ├─ continuing contact
                          └─ native background Job → fresh private child

The TUI shows committed messages and jobs. Commands: /jobs, /job ID, /cancel ID, /stop, /key. Ctrl+C stops the local process; restart restores saved state.

Honest boundaries

The read tool rejects paths outside approved workspaces and Kaeno state, but the process is not sandboxed. Notice admission is not human delivery. Offline application tests pass; a live OpenAI provider call has not been verified with a user key. This is not Pi's stock chat screen or a remote worker system.
